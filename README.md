# AyurBreath AI — Backend

## Setup

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Configure Environment
Edit `.env` with your Gmail credentials for email verification.

## Run
```bash
python app.py
```
Backend runs on `http://localhost:5000`

---

# Frontend

```bash
cd frontend
npm install
npm start
```
Frontend runs on `http://localhost:3000`

---

## Demo Mode
Click **"Try Demo"** on the Login page to use the app without a backend.
